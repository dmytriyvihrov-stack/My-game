>

> request — *"I feel shipped should be in independent file (just in case)"* — for the same reason
> the record was split out of the plan the week before: **the working file should hold only what a
> session can act on**, and a Done table sitting at the top of it is the first thing that goes stale
> and the last thing anybody rereads.

> **Three jobs, three files, and they do not overlap:**
>
> | | |
> |---|---|
> | **This file** | the **registry** — one line per shipped entry, so a number is never reused and no open remainder is lost |

> `CHANGELOG.md` · **a one-line row here** · a test section → [`WHAT_TO_TEST.md`](WHAT_TO_TEST.md).
